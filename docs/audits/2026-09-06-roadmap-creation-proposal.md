# 시간표 홈·로드맵 패널 수정과 개인 로드맵 개선안

## 이번에 반영한 화면 변경

- 시간표 홈을 ‘내 시간표 → 이번 학기 계획 → 지난 시간표’로 정리했다. 저장된 계획을 먼저 보여주고, 과목명·선택 분반 수·계획 학점·수정 시각을 카드에 표시한다.
- 대표 계획의 강조를 파란색으로 통일하고, 이름과 ‘이어서 편집’을 탐색 링크로 제공한다. 계획이 없을 때는 하나의 시작 안내를 보여준다.
- 데이터가 이 브라우저에 저장된다는 사실을 홈에서 안내한다. 성적표로 만든 과거 계획은 실제 수강 분반을 확인해야 한다는 설명도 추가했다.
- 로드맵 프리셋 패널의 내부 가로선과 목록 세로선을 제거했다. 외곽 경계는 옅게 남기고, 만들기 버튼의 점선·그림자를 없앴다. 직접 만들기의 과목 패널과 캔버스 상단 경계도 같은 톤으로 맞췄다.

## 개인 로드맵: 제안 단계

아래는 아직 구현하지 않은 후속 개선안이다. 현재 `CreateRoadmapFlowClient.tsx`와 `RoadmapSidebar.tsx`의 동작을 기준으로 작성했다.

| 우선순위 | 현재 불편                                                                          | 제안하는 동작                                                                                                                                                                             |
| -------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1        | 빈 캔버스에서 모든 과목과 연결을 직접 구성해야 함                                  | 시작 화면에 ‘권장 로드맵으로 시작’과 ‘빈 계획으로 시작’을 제공. 보고 있는 프리셋에서는 ‘이 로드맵으로 내 계획 만들기’로 바로 복사. 원본은 유지하고 개인 계획만 편집한다.                  |
| 1        | 저장할 때마다 새 ID가 생기며, 수정 중인 계획을 자동으로 이어 쓰지 않음             | 계획별 ID·이름을 유지하며 자동 저장. ‘저장됨 / 저장 중 / 저장 실패’를 표시하고 ‘복제’를 별도 명령으로 분리. 삭제 후 되돌리기를 제공한다.                                                  |
| 1        | 드래그만으로 과목을 넣으며 모바일·키보드 사용이 어려움                             | 과목의 ‘추가’ 버튼 → 대상 학기 선택. 학기 열에 자동 정렬하고 카드 메뉴에서 학기를 변경. 드래그는 보조 조작으로 유지한다.                                                                  |
| 2        | 과목을 추가할 때 분류가 일괄 ‘전공’으로 들어가며 계획과 실제 이수가 혼동될 수 있음 | 학사 분류는 카탈로그에서 표시하고, 개인 상태는 ‘이수 / 이번 학기 / 계획’으로 분리. 실제 이수는 성적표와 연결하고 임의 토글로 졸업 판정에 반영하지 않는다.                                 |
| 2        | 연결선의 의미·편집 결과를 이해하기 어려움                                          | 프리셋과 같은 장애물 회피·학기 정렬 사용. 연결 선택 시 관계를 설명하고 삭제 가능하게 한다. 추천 흐름과 편람에서 확인한 선수조건을 구분하며, 사용자가 그린 선은 개인 메모 관계로 표시한다. |
| 3        | JSON 내보내기는 있지만 다시 가져오는 흐름이 없음                                   | 우선 검증된 백업 가져오기와 충돌 처리 제공. 이후 이미지/PDF 공유를 추가한다. ‘기기 저장’과 ‘계정 동기화’는 실제 지원 여부에 맞춰 안내한다.                                                |
| 3        | 로드맵 계획을 시간표로 옮길 때 과목을 다시 찾아야 함                               | 학기 열에서 ‘시간표로 보내기’ → 해당 학기 과목 후보 추가 → 개설 분반 선택. 미개설 과목은 후보로 남기고, 시간표로 보냈다고 이수 완료 처리하지 않는다.                                      |

추천하는 첫 구현 범위는 **프리셋 복사 + 학기별 과목 추가 + 계획별 자동 저장**이다. 사용자가 바로 쓸 수 있는 시작·편집·재방문 흐름을 먼저 완성하고, 요건 잔여량 표시·공유·시간표 연결을 다음 단계로 확장한다.

## 확인

타입 검사와 수정 파일 린트를 확인하고, 브라우저에서 저장된 시간표 카드와 프리셋 패널을 시각적으로 점검했다. 이번 변경은 화면 구성 중심이며 기존 학사 룰셋을 변경하지 않는다.
