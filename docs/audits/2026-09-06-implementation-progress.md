## 1단계: 이수 판정과 추천

기초과학의 분류와 배분을 공통 과목 집합으로 맞췄다. 이수한 강의가 실험 미이수 때문에 목록에서 사라지지 않으며, 실제 분야 충족 여부는 별도로 검사한다. 수학과 자연과학의 초과·미선택 과목은 자유선택 목록에 보존한다.

| 최초 항목                       | 현재 상태           | 수정 또는 확인 내용                                                                                                                                                       |
| ------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 이수현황 단위                | 수정                | 과목 수와 학점 구분은 기존 구현에 있었음. 예체능·콜로퀴움을 학기 수로 수정하고 같은 학기의 중복 과목을 한 학기로 계산함                                                   |
| 2. 이수한 SW기초 추천           | 확인·보완           | GS1490 이수 시 재추천하지 않음. SW기초는 기초과학 3분야와 별도 영역으로 배분함                                                                                            |
| 3. 호환 과목 추천               | 수정                | 글쓰기 요건 충족 시 다른 글쓰기 추천 제외 유지. GS1401→SW 면제는 적용하지만 SW 이수 후 GS1401 추천은 허용. GS/HS 번호와 과목명이 모두 같은 경우 추천에서 제외함           |
| 4. 미적분학·수학 과목 목록 누락 | 수정                | GS1001 및 기존 수학 대체 코드가 배분 과정에서 사라지지 않음                                                                                                               |
| 5. HS 인문사회 오분류           | 수정                | HS2523의 ‘영어’, HS3754의 ‘물리’ 같은 제목 키워드보다 명시적 인문사회 코드 우선                                                                                           |
| 6·10. 시간표 검색·로드          | 로컬 수정·검증 완료 | 실행 디렉터리에 의존하는 파일 읽기를 명시적 서버 번들 import로 변경. 실패한 캐시도 재시도 가능. 운영 복구 여부는 배포 후 확인 필요                                        |
| 7. 대표 개설학과                | 추가 정보 필요      | 원문에서 변경할 동작이 명확하지 않음. 학기별 개설 원본의 학과명을 유지. 로컬 일반화학 검색에 ‘도전탐색과정’이 표시되는 것은 확인함                                        |
| 8. 안보와 무기체계              | 개설 원본 확인 필요 | 전체 카탈로그에는 GS2789/HS2789가 있음. 현재 2026-1·2 분반 원본에는 없으므로 시간표 분반을 임의로 추가하지 않음. GS→HS 중복 추천은 수정함                                 |
| 9. 일반화학 자유학점 오분류     | 수정                | 일반화학 I 단독 이수도 기초과학 진행 목록에 표시. 분야 충족에는 연계 실험 필요. 일반화학 II는 I 대체로 사용하지 않음                                                      |
| 11. 전공탐색                    | 수정                | 기존 UC0902에 학사편람 GS1900을 추가. 반도체공학과 면제 반영                                                                                                              |
| 12. 타대 학점                   | 입력·판정 경로 수정 | 코드 없는 성적표 행 보존, 승인 상태·인정영역 입력 추가, 저장·재계산 시 유지. 승인 확인 중에는 졸업학점에 합산하지 않음. 승인된 영역으로 반영하고 타대 성적은 GPA에서 제외 |
| 13. 학사논문연구 전공학점       | 정상 동작 확인      | 편람 33~34쪽에서 전공과 연구학점은 별도. I/II 6학점은 총학점과 연구 필수 판정에 포함하며 전공학점에 중복 가산하지 않음                                                    |

추천 제외와 졸업학점 중복 인정은 서로 다른 정책이다. GS/HS 번호·제목 일치에 따른 제외는 추천 정책이며, 근거 없는 동등과목 관계를 카탈로그에 새로 만들지 않았다. 기존 동등과목 카탈로그 11개는 유지한다.

## 2단계: 편람에서 함께 발견한 규칙

- 18쪽: 수학 6학점 + 자연과학/프로그래밍 중 3분야. 자연과학은 강의와 연계 실험이 필요하며 실험은 강의와 같거나 이후 학기에 이수한다. 확률과 통계는 2026학번부터 수학 선택에 포함한다.
- 18~19쪽: 2026년 글쓰기 동일과목 정책에 따른 졸업 인정 상한을 적용한다. 2026년 이전 이수자는 기존 인정 대상으로 남긴다. GS1499는 외국인 조건이 필요하므로 자동 충족 대신 확인 필요로 표시하고 일반 추천에서는 제외한다.
- 25쪽: 반도체공학과는 GIST대학 콜로퀴움과 반도체 콜로퀴움을 각각 1학기 이수해야 한다. 수학 콜로퀴움 등 다른 콜로퀴움을 일반 필수에 포함하지 않는다.
- 28쪽: 수리과학 부전공 2026학번의 필수 2+1+1과목과 선택 6학점을 분리한다. 기초과학에 배분된 과목과 필수에 사용한 과목은 선택 6학점에서 제외한다.
- 33~34쪽: 신소재 전공 최소 30학점, 일반 전공 졸업 인정 상한 42학점, 인문사회 36학점, 사회·해외봉사 합계 1학점, 창의함양 1학점을 반영한다. 취득학점과 졸업 인정학점을 구분하고 제외 사유를 남긴다.
- 208쪽: 승인된 타대 인정학점은 최대 30학점, GPA에서는 제외한다.

심화전공 선언·이수 조건과 외국인 학생 구분을 입력받는 기능은 아직 없다. 이런 예외가 판정에 영향을 주는 경우 확인 필요 상태로 남는다. 전공 상한을 적용해도 이미 130학점을 충족하면 상한 예외만을 이유로 졸업 충족을 막지 않는다. 타대 인정영역만으로 개별 필수과목의 대체 이수를 추측하지 않으며, 학교가 승인한 GIST 대응 코드가 필요하다.

카탈로그 구조 검사 통과가 편람 전체 구현 완료를 의미하지는 않는다. 복수전공·심화전공, 과거 학번 특례, 일부 전공별 공유·중복 인정 제한은 기존 `catalog-source-page-audit.ts`의 후속 범위로 남긴다.

## 3단계: 시간표와 로드맵

- 시간표 14개 학기 데이터를 서버 번들에 포함한다. 로딩 실패를 캐시하지 않는다.
- 로드맵 과목 카드가 현재 저장된 성적표의 이수 과목을 읽어 ‘이수 완료’ 표시를 한다. F/U·미확정·수강 중·승인 확인 중 과목은 완료 표시하지 않는다.
- 프리셋의 실선은 요구하는 변경 동작이 명확하지 않아 유지했다.
- 비로그인 사용은 기존 지원 상태를 유지하고 시간표 생성·검색·추가 흐름으로 확인했다. 강의평가 기능은 추가하지 않았다.
