## 근거와 범위

졸업요건의 기준은 `docs/bachelor_manual/2026_manual.pdf`이다. 입학 연도별 경과조치는 이 편람의 적용 문구를 따른다. `docs/wiki`, `DB/minor/*.json`, 프리셋, CSV는 규정의 근거로 사용하지 않는다. 과거 이수 과목의 존재·코드·학점에는 저장소의 2020~2026 학사편람 추출 자료를 보조로 사용한다. 개설 여부는 실제 학기별 분반 자료로 별도 판단한다.

집중 대조: 편람 18~34쪽의 공통·전공·부전공 요건, 49~51쪽 인문사회 과목표, 55쪽 문화기술·지능로봇 과목표. 27~28쪽의 병합된 표는 렌더링으로 확인했다. 모든 교과목의 선수조건이나 학사행정 절차까지 자동 판정된다는 의미는 아니다.

## 위키·원천 데이터 신뢰도

- `DB/minor/*.json`의 `Major Mandatory` 구분을 필수 규정으로 사용하지 않는다. 과목 후보는 편람 목록, 필수 여부는 적용 조건이 있는 룰셋에서 가져온다.
- 부전공 카탈로그의 과목명·학점은 편람 메타데이터를 우선한다. 편람 제목 추출이 없는 과거 과목의 표시명에는 기존 메타데이터가 남을 수 있다.
- 부전공 facet의 원문은 과목별 편람 연도·페이지로 연결한다.
- 기존 `course-code-sets.ts`는 남아 있는 레거시 자료이며 전공·부전공 매칭의 원장으로 쓰지 않는다.
- 프리셋의 분류·학기·연결선은 추천 학습 계획이다. 개인의 필수 졸업요건이나 실제 선수강 강제조건으로 해석하면 안 된다.

## 화면 변경

### 시간표

주간표를 왼쪽의 주 영역으로 배치하고 검색 패널을 오른쪽에 두었다. 검색창과 학과 필터를 분리하고, 긴 제목은 두 줄까지 표시한다. 강의 추가 버튼과 이미 담은 수업의 강조를 정리했다. 기본 범위는 09~19시이며 이른/늦은 실제 수업과 미리보기까지 자동 확장한다. 빈 주말만 접고 주말 수업·미리보기가 있으면 자동으로 요일을 표시한다. 모바일 요일 최소 너비 때문에 마지막 열이 잘리던 부분도 수정했다.

### 로드맵

- 저장된 프리셋 좌표에 상관없이 학기별 열 정렬, 열 안에서는 연결 관계를 사용해 순서 조정.
- 카드 224×116, 열 간격 336, 행 간격 164. 학기 미지정 노드는 버리지 않고 별도 열로 유지.
- 전체 보기, 학년별 확대, 학기별 재정렬. 프리셋 목록은 처음에는 접어 캔버스 공간 확보.
- ID 문자열 추측을 제거. 노드 사각형을 장애물로 보는 직교 경로 탐색과 둥근 모서리 적용. 중간 학기의 카드를 가로지르는 선을 우회.
- 평상시 점선은 추천 흐름, 선택/포커스 관계는 강조. 중첩된 버튼 역할을 제거하고 키보드 포커스에도 연결 관계 표시.
- 로컬 저장 상태에 따른 서버/클라이언트 초기 HTML 불일치 수정.
- 사용자가 편집 중 카드를 겹치게 배치해 경로가 없으면 그 연결은 임의로 카드를 관통하지 않고 숨긴다. 재정렬하면 다시 표시된다.

참고한 설계 원칙: [roadmap.sh Frontend](https://roadmap.sh/frontend)의 계층·분기 정렬과 연결 의미 구분, [React Flow layout 문서](https://reactflow.dev/learn/layouting/layouting)의 배치/선 경로 분리, [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)의 키보드·포커스·넘침 점검. 외부 서비스의 선수과목 관계나 콘텐츠를 복사하지 않았다.

### 졸업요건 안내

입학 연도(2018~2026)와 전공 선택, 공통 요건, 전공필수, 부전공별 펼침 목록으로 재구성했다. 학점·필수 과목은 서버에서 같은 룰셋으로 생성하여 클라이언트에는 안내용 데이터만 전달한다. `public/academic-manual/2026.pdf`는 원본의 동일 사본이며 각 근거 페이지로 바로 연결한다.

## 자동 확정하지 않는 부분

1. IR 지정 AI 전체 목록과 이전 선언자의 기이수 교과목 경과조치. 편람에 없는 임의 AI 코드를 인정하지 않는다.
2. 2020 이전 인문사회 단일/연계/개편 체계 선택. 필수과목 충족으로 임의 확정하지 않는다.
3. 부전공 선언 후 정규 1학기 이상 수학, 복수·심화전공, 특례 승인, 외국인 자격. 입력 모델과 승인 자료가 더 필요하다.
4. 전체 공유과목의 모/자 관계와 모든 과거 동일·대체과목의 원문 대조. 현재 알려진 관계와 명시 코드만 자동 처리한다.
5. 2018 이전 학번의 모든 경과요건, 2026 이후 편람 변경은 이번 안내 범위 밖이다.
6. 시간표 실제 운영 환경의 500 재발 여부는 배포 후 확인이 필요하다. 편람의 개설 계획은 실제 분반 게시를 대신하지 않는다.

## 최종 검증 기록

### 후속 정정: 영어 I의 개편 전 과목 인정

2021년 2학기 GS1603 단독 이수 제보로 추가 확인했다. 2021 편람 인쇄 18쪽(PDF 19쪽)은 GS1601 신입생 영어 **또는** GS1603 발표와 토론 중 1과목 2학점을 요구한다. 2026 편람 167쪽의 GS1607 설명인 ‘Replaces both GS1601 and GS1603’을 기존 두 과목을 모두 이수해야 한다는 조건으로 해석한 구현은 잘못됐다. 앞선 점검에서 이 부분을 놓쳤다.

2021 이후 입학생에게 적용되던 AND 조건을 제거하고, 판정이 카탈로그의 인정 코드 목록을 직접 사용하게 수정했다. 안내에서 ‘동시 이수’를 제거하고 2021 편람을 과거 영어 I 인정의 근거로 등록했다. GS1603 및 GS1601의 2021년 2학기 단독 이수 회귀 테스트를 추가했으며, 전체 56개 스위트·294개 테스트와 카탈로그 검증을 통과했다. 영어 II는 별도 요건으로 유지한다.

- 회귀 테스트: 56개 스위트, 293개 테스트 통과. 전공·부전공 경계 사례, 공유 코드, 시간표 주말 표시, 로드맵 장애물 회피를 포함한다.
- 룰 카탈로그: 188개 규칙·11개 동일/대체 관계의 스키마, 컴파일, 직렬화, 근거 참조 및 스냅샷 검사 통과.
- 과목 카탈로그: 1,233개 과목, 1,479개 별칭, 5,548개 개설 항목 검증 통과. 구조 검증 통과가 모든 과거 과목 관계의 원문 대조 완료를 의미하지는 않는다.
- 타입 검사와 프로덕션 빌드 통과. 린트 오류 없음, 기존 경고 14개 유지. 서버 시간표 번들 및 클라이언트 카탈로그 경계 검사 통과.
- 브라우저: 비로그인 상태의 시간표·졸업요건 안내·로드맵 접근 확인. 프로덕션 시간표에서 일반화학 10개 분반 검색 및 저장된 수업 표시 확인. CS 코어 로드맵에서 학기 헤더 포함 37개 노드와 20개 연결 경로 렌더링 확인.
- 화면 점검: 데스크톱과 좁은 모바일 화면에서 안내·시간표의 문서 가로 넘침 점검. 모바일 시간표 마지막 요일 잘림을 수정했다. 학년별 로드맵 확대와 상세 조회도 확인했다.

- 로컬 브랜치에서 검증했으며 커밋·푸시·배포는 수행하지 않았다. 도메인 복구는 이번 범위에서 제외했다.
