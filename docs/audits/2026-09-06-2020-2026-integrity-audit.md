# 2020–2026 학사편람·카탈로그 정합성 감사

2026-09-06 재점검 및 후속 수정 결과. 작업 브랜치는 `codex/fix-academic-rules-and-timetable`이며 도메인 복구는 제외했다. 이 문서는 같은 날의 초기 감사에서 남겼던 미해결 목록을 갱신한다. 원본 해시, 코드별 이력과 전체 관측 목록은 [구조 감사 JSON](2026-09-06/handbook-integrity.json)에 있다.

## 판단 기준

- 졸업 규정은 학사편람의 **적용 학번·선언 학기·경과조치**를 우선한다. 편람 발행연도가 곧 적용 입학연도는 아니다.
- 과거 이수의 코드·학점은 해당 연도 근거와 성적 이력을 보존한다. 현재 과목 표시값으로 과거 이력을 덮어쓰지 않는다.
- 위키, `DB/minor` JSON, CSV alias와 로드맵은 구현·관측 자료이며 학사 규정의 원문이 아니다.
- 실제 개설·분반·시간은 수강신청 원본을 사용한다. 편람 수록만으로 현재 개설되었다고 표시하지 않는다.
- 원문에 없는 승인·대체 관계는 자동 인정하지 않는다. 코드 충돌과 이력 누락은 정보 부족과 구별하여 구현에서 해결한다.

페이지는 모두 PDF의 **물리 페이지**다. 2020/2022/2023은 한 PDF 면에 인쇄 두 쪽이 들어가며, 2021/2024/2025는 PDF와 인쇄 번호가 보통 1 차이 난다.

- 현재 개설 관측이 없는 편람 수록 과목 219개, 편람 제목 추출에 없는 개설 과목 353개. 수록·개설 계획·실제 개설의 차이를 오류로 단정하지 않는다.

`needs_review`는 필요한 조건을 확인할 수 없다는 뜻이다. 게시 규칙 개수나 구조 통과를 모든 학생·모든 예외의 졸업 보증으로 해석하지 않는다. 과목명·학과가 현재 표시 자료인지 해당 연도 근거인지도 구분해야 한다.

## 재현 명령

```sh
# macOS PDFKit/Vision OCR. 원본 해시와 전체 페이지를 기록한 캐시 사용.
swiftc scripts/course-catalog/ocr-handbook.swift -o /tmp/ocr-handbook
/tmp/ocr-handbook docs/bachelor_manual/2021_manual.pdf /tmp/handbooks/2021
/tmp/ocr-handbook docs/bachelor_manual/2022_manual.pdf /tmp/handbooks/2022
npm run course-catalog:extract-manual-listings -- --ocr-cache-root /tmp/handbooks
python3 scripts/graduation/build-manual-course-metadata.py
npm run course-catalog:export -- --out features/course-catalog/generated/course-catalog.snapshot.json
npm run graduation:catalog:export -- --out tests/fixtures/graduation-catalog-publish-bundle.snapshot.json
npm run course-catalog:audit-handbooks -- --out docs/audits/2026-09-06/handbook-integrity.json
npm run jest -- --runInBand --no-watchman
npm run typecheck
npm run lint
npm run build
```

기본 OCR fallback에는 Tesseract `kor+eng`가 필요하다. 외부 캐시는 PDF 해시·쪽수 및 연속된 전체 페이지 파일을 검증한다. 검수 교정은 원본 해시가 바뀌면 적용을 거부한다. 생성 snapshot은 export 명령의 직렬화 결과를 유지하며 별도로 포맷하지 않는다.

- Jest 60개 suite, 328개 테스트 통과.
